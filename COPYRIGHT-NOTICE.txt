Source code
-----------
The complete corresponding source code for every binary released by this project
is public at:

    https://github.com/masadzim/SelfMusic-Studio

Per GPL-3.0 section 6, you may convey the object code by offering access to the
corresponding source. That repository already contains the full source needed to
build this program, including:

  SelfMusic-Studio.html        renderer (the whole UI)
  electron/main.cjs            main process
  electron/preload.cjs         preload bridge
  electron/tts.cjs             offline TTS engine (eSpeak NG + Piper)
  scripts/prepare-tts-assets.* reproducibly fetch the bundled assets
  resources/tts/               bundled eSpeak NG + Piper model

To build from source you need no API keys and no network access:

  npm install
  npm run prepare:assets
  npm start
